# Datos de demostración

- `gateway.json`: respuesta simulada que consume `js/app.js` para mostrar el catálogo.
- `productos.json`: lista local de referencia con el mismo catálogo.

Ambos archivos son JSON válido y contienen únicamente datos de presentación. No son APIs de servidor, no guardan pedidos ni contienen datos de clientes. Para editarlos, conserva los nombres de campo que usa la interfaz.
